# Архитектура FlowGuard Таблицы

## Результат

Программа превращает смешанные рабочие записи в понятную очередь проверки. Она
не отправляет таблицу в облако и не позволяет статистической модели самой
совершать действия с данными.

## Движение данных

```text
Excel / CSV / JSON
   |
   v
Проверка входного файла и приведение данных к единому виду
   |
   +--> Группировка контактов и поиск повторов
   +--> Поиск необычных сумм устойчивым статистическим методом
   +--> Локальное распознавание смысла комментариев
   |
   v
Расчёт оценки риска и формирование понятных причин
   |
   +--> Очередь проверки в интерфейсе
   +--> История запусков в локальной базе SQLite
   +--> Отчёты Excel и CSV
```

## Основные решения

### Минимально необходимая модель

Используется небольшой локальный классификатор, а не автономный агент. Его
единственная задача — определить тему комментария. Все проверки и оценки риска
выполняются по явным правилам. Дополнительная автономность повысила бы риск, но
не дала бы полезного результата для этой задачи.

### Граница полномочий

Классификатор может присвоить комментарию тему. Он не может изменить статус,
связаться с человеком, удалить запись или подтвердить оплату. Следующее действие
выбирает пользователь.

### Объяснимость

У каждой записи есть:

- числовая оценка риска;
- признаки найденных проблем;
- причины обычным языком;
- предполагаемая тема комментария;
- уверенность классификатора;
- слова, повлиявшие на классификацию, если они доступны.

### Хранение истории

SQLite — это небольшой локальный файл базы данных. В нём каждый завершённый
результат хранится как неизменяемый снимок вместе со сводными показателями.
Ошибочная загрузка не записывается как завершённая проверка.

## Условия проверки качества

- точность классификатора на контрольных примерах не ниже 70 процентов;
- один российский телефон в форматах `8...` и `+7...` должен совпадать;
- просьба об отмене при активном статусе должна создавать предупреждение;
- заметно отличающаяся сумма должна обнаруживаться на корректном примере;
- пустой комментарий должен обрабатываться как нейтральный;
- загрузка более 5 000 строк должна безопасно отклоняться.

## Границы версии 0.1.0

Версия рассчитана на одного пользователя и локальный компьютер. Для общего
корпоративного сервера понадобятся авторизация, разграничение прав, настройка
сроков хранения, резервные копии, журналирование, ограничения нагрузки и
отдельная проверка порядка работы с персональными данными.
