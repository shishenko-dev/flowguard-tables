# Быстрый запуск FlowGuard Таблицы

## 1. Запуск

Если вы получили готовую Windows-версию, дважды нажмите
`FlowGuardTables.exe`. Программа сама откроется в браузере.

Если вы запускаете исходный код, откройте PowerShell в папке программы и
выполните:

```powershell
python -m pip install -r requirements.txt
.\run.ps1
```

В браузере откройте <http://127.0.0.1:8787>.

## 2. Проверка примера

Нажмите «Запустить пример». Программа покажет сводку, очередь строк по
важности и полную таблицу. Все имена и контакты в примере вымышлены.

## 3. Проверка своей таблицы

1. Сохраните таблицу в формате Excel `.xlsx` или CSV.
2. Нажмите «Проверить свою таблицу».
3. Выберите файл размером до 15 МБ.
4. Проверьте количество строк и список распознанных проблем.
5. Используйте фильтры «Нужно проверить», «Повторы» и «Суммы».
6. Нажмите «Скачать Excel», чтобы получить итоговый файл.

Программа читает первый лист Excel. Исходный файл не меняется.

## 4. Что означает оценка риска

Оценка от 0 до 100 помогает расположить строки по важности. Она не является
финальным решением и не удаляет запись. Рядом с оценкой всегда указана причина:
например, отсутствующий контакт, повтор, неверная дата или необычная сумма.

## 5. Если столбцы не распознаны

Используйте понятные названия: «Клиент», «Телефон», «Почта», «Дата», «Статус»,
«Сумма», «Комментарий», «Источник» и «Ответственный». Достаточно хотя бы одного
распознанного столбца, но лучший результат получается при наличии клиента и
контактных данных.
