# Отчёт о проверке FlowGuard Таблицы 0.1.0

Дата проверки: 3 сентября 2026 года.

## Проверенная среда

- Windows 11;
- Python 3.12.13 для проверки исходного кода;
- PyInstaller 6.22.2 для сборки самостоятельного файла Windows;
- современный встроенный браузер Codex для визуальной проверки.

## Выполненные проверки

1. Запущены 12 автоматических проверок. Результат: 12 успешно, ошибок нет.
2. Проверен синтаксис клиентского JavaScript. Ошибок нет.
3. Проверена компиляция файлов Python. Ошибок нет.
4. Собран самостоятельный `FlowGuardTables.exe`.
5. Собран архив `FlowGuardTables-0.1.0-windows.zip`.
6. Запущен именно собранный `.exe`, а не исходный код.
7. Проверен служебный ответ программы: состояние `ok`, название
   `FlowGuard Таблицы`, версия `0.1.0`.
8. Загружен встроенный набор из 12 вымышленных строк.
9. Получен ожидаемый результат: 9 строк требуют внимания, 2 группы повторов и
   1 необычная сумма.
10. Сформирован и скачан настоящий отчёт Excel.
11. Ранее отдельно проверена загрузка настоящего файла `.xlsx` через выбор
    файла в браузере.
12. Визуально проверены главный экран, результаты, русские имена, статусы,
    причины и адаптивная вёрстка.

## Покрываемые случаи

- российские телефоны в разных форматах;
- русские и английские названия столбцов;
- CSV, JSON и первый лист Excel;
- повторяющиеся контакты;
- конфликт статуса и комментария;
- необычная сумма;
- пустой комментарий;
- безопасный отказ при превышении 5 000 строк;
- защита выгрузки от формул, начинающихся со служебных символов.

## Что этот отчёт не доказывает

Проверка не является независимым аудитом безопасности и не подтверждает работу
на всех возможных таблицах. Версия 0.1.0 предназначена для локальной работы
одного пользователя. Корпоративное внедрение требует проверки на обезличенной
копии конкретной таблицы и письменного согласования критериев приёмки.
