# FlowGuard Таблицы 0.1.0

Первый публичный проверяемый выпуск локальной программы для контроля таблиц.

## Главное

- готовая Windows-версия запускается одним `.exe`;
- загрузка первого листа Excel, CSV и JSON;
- русские и английские названия столбцов;
- поиск повторов, пропущенных контактов, неверных дат, необычных сумм и
  противоречий между статусом и комментарием;
- очередь проверки с объяснением каждой причины;
- выгрузка нового отчёта Excel и CSV;
- локальная история в SQLite;
- отсутствие облачных запросов, аналитики и ключей платных моделей;
- 12 автоматических проверок.

## Как проверить

1. Скачайте `FlowGuardTables-0.1.0-windows.zip`.
2. Сверьте контрольную сумму SHA-256, указанную на странице выпуска.
3. Распакуйте архив.
4. Запустите `FlowGuardTables.exe`.
5. Нажмите «Запустить пример».

SHA-256 — это цифровой отпечаток файла. Совпадение отпечатка помогает убедиться,
что архив не изменился после публикации.
